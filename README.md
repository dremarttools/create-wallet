# Dremart Wallet

Dremart Wallet is a browser-based multi-chain wallet for creating, importing, and managing digital assets.

## Features

- Create new wallets in the browser
- Import wallets using recovery phrases, private keys, or keystore files
- Support for Bitcoin, Ethereum, BNB Chain, Base, Polygon, Arbitrum, Optimism, Avalanche, and Solana
- Send and receive supported assets
- Token swaps and cross-chain bridging
- Encrypted wallet storage in the browser
- Affiliate referral program
- Progressive Web App support

## Security

Dremart Wallet is not security audited. Use it at your own risk.

- Never share your recovery phrase or private key.
- Always verify the website address before entering wallet information.
- Keep an offline backup of your recovery phrase.
- Do not use real funds until the code has been independently reviewed.
- Never commit database passwords, API keys, private keys, or `.env` files.
